<img width="1346" height="718" alt="image" src="https://github.com/user-attachments/assets/d5fe5abe-d9c4-4144-a0aa-f0066f6ed235" /># 🏥 Clinic Management System (CMS)

A **user-friendly and efficient** Clinic Management System designed to **automate** and **streamline** the operations of a medical clinic in Sri Lanka. The system replaces manual paper-based workflows with a **digital solution** for managing **patients, doctors, appointments, billing, inventory, and reports**.

## 🚀 Features
- **👨‍⚕️ Patient Management** – Digital registration, appointment scheduling.
- **🩺 Doctor & Consultation Module** – Queue management, digital prescriptions, and lab test requests.
- **💳 Billing & Payment System** – Automated invoicing, multiple payment methods (**cash-focused**).
- **🏥 Inventory & Pharmacy Management** – Medicine stock tracking, low-stock alerts, expiry monitoring.
- **🔒 Role-Based Access Control** – Secure logins, authentication, and audit logs.
- **📊 Reporting & Analytics** – Patient statistics, revenue tracking, and stock reports.
- **🛡️ Data Security & Backup** – Local storage with optional cloud backup.

## 🛠 Tech Stack
- **Language:** Java (Spring Boot)
- **Database:** MySQL
- **Security:** Role-based Access Control
- **Development Environment:** IntelliJ IDEA


## 🎯 Project Goals
- **Increase efficiency** in clinic operations by reducing paperwork.
- **Enhance doctor-patient interactions** through a seamless system.
- **Improve data accuracy & security** with role-based access and encryption.
- **Optimize inventory tracking** and avoid medicine shortages.

## 🚀 Installation & Setup

### Prerequisites
- **IntelliJ IDEA** (Recommended IDE)
- **Java 17+**
- **Maven** (for dependency management)
- **MySQL** (Database)
- **Git** (Version Control)
